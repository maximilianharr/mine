A task carries the three keys an event never has: `stage`, `important` and `estimate`.

- `stage` is `todo`, `doing` or `done` and is the only record of progress - there is no
  `done` flag.
- `important` is a plain yes or no, and only `true` is ever written: a task that is not
  important carries no key at all. There is no priority scale and no `priority` key.
- `estimate` is in days. It has no RFC 5545 equivalent, so the name is ours.

There is no `sprint` key. The sprint is whichever range in `settings.md` this `start` falls
in, so the number can never disagree with the date, and moving the card to another sprint is
exactly a change of `start`. With the anchor and interval in `sample/settings.md` this one is
in sprint 8, 13-26 April 2026.
